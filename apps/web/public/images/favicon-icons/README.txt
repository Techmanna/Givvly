Favicon package

Files:
- favicon.ico: multi-size browser favicon (16, 32, 48 px)
- favicon-16x16.png and favicon-32x32.png: standard browser PNG favicons
- apple-touch-icon.png: 180 px Apple touch icon
- android-chrome-192x192.png and android-chrome-512x512.png: Android/PWA icons
- favicon-*.png: additional common sizes
- site.webmanifest: PWA icon manifest

All icons use a transparent background and retain the original gold mark.
